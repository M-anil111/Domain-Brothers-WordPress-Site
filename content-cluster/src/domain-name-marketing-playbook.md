Domain name marketing starts from a simple fact: a premium domain is only as valuable as the marketing built on it. The good news is that a short, clear name makes every channel a little cheaper and every message a little easier to remember. This playbook shows where and how to use the name, with a 30 day plan to launch it. It is part of our [complete guide to premium domain names](/premium-domain-names-complete-guide/).

!takeaways In short
- Put the name on every touchpoint: email, ads, print, social profiles and packaging.
- Use short, memorable addresses for campaigns so people can type them from memory.
- Measure everything with tagged links and conversion goals.
- Follow a plan, so the name starts working in the first month.

## 1. Branded email

Every email you send carries your domain. A professional address builds trust before the message is read, and it is the cheapest advertising you will ever do.

- Use real names or roles: `name@yourdomain`, `hello@`, `sales@`.
- Set up SPF, DKIM and DMARC so messages reach inboxes. See our [launch checklist](/website-launch-checklist-after-buying-a-domain/) and the [DMARC overview](https://dmarc.org/overview/).
- Add a short signature with your name, role, phone and website.
- Move every team member off free webmail addresses. One person writing from a free address undoes the trust the rest of the team builds.

## 2. Paid advertising

A short, readable domain looks better in the ad's display URL and is easier to remember after one view.

- Use the name in headlines and display URLs where the platform allows.
- Send ad traffic to dedicated landing pages on the same domain, so the brand builds with every click.
- Track results with campaign tags on every link.
- Use branded search ads to protect your own name from competitors.
- Match the ad, the display URL and the landing page headline, so people see the same promise from the first view to the form.

## 3. Print, QR codes and events

Short names are easy to read from a slide or a sign, which makes offline channels some of the cheapest wins in domain name marketing.

- Put the domain, not a long link, on business cards, packaging, vehicles and banners.
- For a campaign, use a QR code that points to a short, memorable page on your domain, and test it on several phones.
- Repeat the address aloud in talks and videos; short names make this natural.
- In print, capitalise each word of a two-word name, such as `BlueRiver.com`, so it reads at a glance. Domains are not case-sensitive, so the link still works.

## 4. Social profiles and handles

Use the same name on every platform. If the name is not available everywhere, keep the closest consistent version, and link each profile to the website. We can help you [acquire social media handles](/acquire-social-media-handles/) that match your domain.

- Put the full domain in every profile's bio and link field.
- Use the same logo, colours and short description everywhere, so people recognise you between platforms.
- Pin a post that introduces the website and what visitors will find there.
- Point profile links to a page built for that audience, tagged so you can see which platform sends visitors.

Consistent handles are one of the cheapest parts of domain name marketing, and one of the easiest to neglect.

## 5. Vanity URLs and campaign pages

A vanity URL is a short, memorable address that forwards to a longer page, such as `yourdomain/spring` or a campaign on a short second name.

- Choose words people can say and spell.
- Always forward with a permanent or temporary redirect, as fits the campaign.
- Tag the destination so you can see which channel brought each visitor.

## 6. Search and content

A great domain does not rank by itself, but it helps in the ways that matter: people click it, remember it and search for it by name. Pair it with helpful content. Read [Do Premium Domains Help SEO?](/do-premium-domains-help-seo/) for the details, and follow Google's [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) for the basics.

## 7. Word of mouth

The ultimate test is whether a customer can hear your name once and type it correctly. If the answer is yes, every happy customer becomes a marketing channel. Keep the name easy to say, and ask for referrals in your emails and receipts.

Test it with the radio test: say the name once to someone who has never heard it and ask them to write it down. If they spell it right, every conversation, podcast mention and phone call works for you. If they do not, own the common misspellings and redirect them, as described below.

## A 30 day domain name marketing plan for a new name

**Week 1: Foundation**
1. Secure the domain, connect DNS and turn on HTTPS.
2. Set up branded email with authentication.
3. Publish the home, about and contact pages.
4. Add analytics and Search Console.

**Week 2: Presence**
1. Claim matching social handles and complete each profile.
2. Update your email signature and every place the old name appears.
3. Tell your customer list about the new address.
4. Submit your sitemap and check indexing.

**Week 3: Campaigns**
1. Create one landing page for each main offer.
2. Launch a small paid campaign to the landing pages.
3. Print or share a QR code at one event or in one mailing.
4. Reach out to partners for links and mentions.

**Week 4: Measure and improve**
1. Review conversions by channel.
2. Fix the weakest page and double the best channel.
3. Publish a helpful article that answers a common question.
4. Plan the next month.

## Using extra domains in your domain name marketing

Many brands own more than one domain. Used well, the extras protect the main name and make campaigns easier to remember.

- **Common misspellings and other extensions** catch visitors who type the name wrong. Redirect each one to the main site with a permanent (301) redirect.
- **A short campaign domain** can be easier to say on radio, a podcast or a billboard. Point it at a matching page on the main site, not at the home page.
- **An old domain after a rebrand** keeps its value as long as it redirects page by page to the new one.

Do not publish the same content on several domains. Keep one main site and let the others redirect to it, so every link and mention builds the same brand.

### Domain name marketing during a rebrand

When a premium domain replaces an older or longer name, the change is itself a marketing moment. Announce it to customers by email, explain what changes and what stays the same, and update every profile and printed item in the same week. Keep the old domain and its redirects for at least a year. ## Measuring domain name marketing

If you cannot see which channel brought a visitor, you cannot decide where to spend next month's budget. Set up measurement before the first campaign.

- **Tag every campaign link** with source, medium and campaign parameters, so your analytics tool groups visits by channel.
- **Give each print or event campaign its own page or vanity address.** Visits to that page tell you what the flyer or talk achieved.
- **Track conversions**, not only visits: form submissions, calls, bookings and sales.
- **Watch brand searches** in Search Console. When more people search for your name, the domain is sticking in their memory.
- **Count direct visits.** People who type the address from memory are a sign that the name works.

Review the numbers every month, keep what works and stop what does not.

## Mistakes to avoid

- Changing the name between campaigns.
- Using long, hard-to-type links in print.
- Sending ad traffic to the home page instead of a focused page.
- Forgetting to authenticate email.
- Not tracking where leads come from.
- Treating domain name marketing as a one-off launch task instead of a monthly habit.
