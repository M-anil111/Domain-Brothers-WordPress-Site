# Domain Brothers website

WordPress site for Domain Brothers, a premium domain marketplace. All custom code is the `db-custom-blocks` plugin.

See [CLAUDE.md](CLAUDE.md) for the system overview, how to test and deploy, where secrets live (names only) and how errors are reported. `MARKETPLACE_PLAN.md` describes the planned seller marketplace; `GO_LIVE_CHECKLIST.md` covers the move from staging to production.
