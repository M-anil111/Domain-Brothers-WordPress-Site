# Bug register, batch 2 (2026-11-22, plugin 3.144.8)

**210 distinct defects: 24 high, 87 medium, 99 low.** 124 were reproduced on https://beta.domainbrothers.com; 86 are pinned to a file and line with a failing input.

Method: eleven parallel reviews, each covering one area with a line-by-line read of the plugin code and read-only checks on beta (browser, HTTP probes with malformed input, axe-core, keyboard tests, read-only database queries). Nothing on beta was changed. Findings already in `docs/BUG_REGISTER.md` (batch 1) or `docs/DESIGN_QA.md` were excluded; duplicates found by more than one review were merged (15 merges), one finding that no longer reproduced was dropped, and one finding from an external scan was confirmed in code and added (CK, double sale); the other external claims were duplicates or did not hold.

Severity: **H** high, **M** medium, **L** low. Effort: **S** under 1 hour, **M** half a day, **L** a day or more. Verified: **live** reproduced on beta, **code** read from the code with a concrete failing case.

**Status:** 154 fixed, 56 open.
