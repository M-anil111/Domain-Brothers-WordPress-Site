# Legacy snippet files (not used)

These are the original standalone `db_*_block.php` files that were once pasted
into the theme's `functions.php`. Their code now lives inside the
`db-custom-blocks` plugin (every function they define exists there; the old
services menu was replaced by the mega menu in `db-header-block.php`). Nothing
here is loaded. They are kept only for history; do not paste them back into
`functions.php`, which would only be blocked by the plugin's double-load guard.
